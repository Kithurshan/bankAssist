# BankAssist AI

AI-powered banking chatbot system for Sri Lanka.

## Features
- Chatbot with ML (TF-IDF + Decision Tree)
- Admin panel
- Self-learning system
- Emotion detection
- User authentication

## Tech Stack
- Frontend: React
- Backend: FastAPI
- Database: PostgreSQL (Neon)
- ML: Scikit-learn

## Setup

### Backend
cd backend
pip install -r requirements.txt
uvicorn main:app --reload

### Frontend
cd frontend
npm install
npm run dev
